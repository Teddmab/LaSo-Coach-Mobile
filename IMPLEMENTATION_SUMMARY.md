## 🔄 Migration Path

### Before (Non-Compliant)
```javascript
// ❌ Opened external browser for payment
const checkoutData = await SubscriptionApi.createStripeCheckoutSession();
await Linking.openURL(checkoutData.url); // VIOLATION
```

### After (Compliant)
```javascript
// ✅ Uses native store (App Store / Google Play)
await IAPService.requestPurchase(productId, true);
// Receipt validated server-side before unlocking
await IAPReceiptApi.validateReceipt(receiptData);
```

## 🔐 Security Model

```
User taps Subscribe
       ↓
Native IAP initiated (App Store / Google Play)
       ↓
User completes payment in native flow
       ↓
Receipt generated by platform
       ↓
App sends receipt to YOUR backend
       ↓
Backend validates with Apple/Google
       ↓
Backend grants access in database
       ↓
App unlocks premium features
```

**Critical**: Never unlock content client-side. Always validate server-side.

## 🆘 Troubleshooting

### Common Issues & Solutions

**"Products not found"**
```
Problem: Store product IDs don't match
Solution: Verify IDs are exactly:
  - com.laso.coach.premium_monthly
  - com.laso.coach.premium_yearly
  etc.
```

**"Receipt validation fails"**
```
Problem: Backend configuration issue
Solution: Check:
  - Apple shared secret is correct
  - Google service account has permissions
  - Using correct endpoint (sandbox vs production)
```

**"Purchase doesn't unlock content"**
```
Problem: Backend not granting access
Solution: Check backend logs:
  - Receipt validation succeeded?
  - Database updated correctly?
  - User record updated?
```
